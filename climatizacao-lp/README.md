# Template Code Makers — Climatização

Template demonstrativo em Next.js para sites de instalação e manutenção de ar-condicionado. O conteúdo e as imagens são ilustrativos. Nenhum botão abre telefone, WhatsApp, mapas ou redes sociais; as chamadas de contato levam à área de personalização no rodapé.

## Executar localmente

Requer Node.js 22.13 ou superior.

```bash
npm ci
npm run dev
```

Acesse `http://localhost:3000`.

## Antes de publicar

- Substitua o texto “Template Code Makers” pela identidade autorizada do projeto.
- Atualize textos, serviços, área atendida, horário e imagens conforme o negócio.
- Configure canais de contato reais e revise cada chamada para ação.
- Atualize os metadados em `app/layout.tsx` e o manifesto em `app/manifest.ts`. O template vem com `robots.index: false`.
- Remova as orientações de demonstração após personalizar o site.

## Verificação

```bash
npm run lint
npm run build
```
